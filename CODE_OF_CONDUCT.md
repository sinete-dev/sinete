# Código de conduta

O sinete adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([tradução em português](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)) como código de conduta para todos os espaços do projeto: repositório, issues, PRs, discussões e eventos.

Em resumo: participe com respeito, aceite crítica técnica sem levar para o lado pessoal, e não tolere assédio, discriminação ou ataques de qualquer tipo.

## Como reportar

Relatos de violação vão para os mantenedores de forma privada, pelo mesmo canal de reporte privado do GitHub descrito em [SECURITY.md](SECURITY.md), indicando no título que se trata de conduta. Todo relato é analisado e mantido em sigilo; as medidas seguem as diretrizes de aplicação do Contributor Covenant 2.1.
